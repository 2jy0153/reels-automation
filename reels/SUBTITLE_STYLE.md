# 릴스 자막 스타일 규칙 (stark.m0de)

릴스 자막(SRT)을 만들거나 수정하라는 요청이 오면 아래를 따른다.

## 1. 주제 색을 먼저 묻는다

답이 오기 전에는 SRT를 만들지 않는다.

질문: "이 영상의 주제 색은?"

1. 블루 `#A6D9FF` — 디지털
2. 그린 `#AEFFCA` — 창업
3. 오렌지 `#FFB56E` — 콘텐츠 제작
4. 노랑 `#FFEB6B` — 템플릿 공유 등 이벤트

고르면 한 번 더 확인한다. 색은 사용자가 보낸 값 그대로 쓴다. 한 영상에는 색 하나만 쓴다.
`srt` 명령은 `--color` 값이 없으면 실행되지 않는다.

## 2. 스타일 규격

- 시퀀스: 1080×1920(9:16) 기준
- 위치(고정): 박스 윗변을 화면 높이 27%(y=518px)에 두고 가로 가운데. 두 줄이면 줄 사이 간격은 글자 크기의 약 0.18배. 위 14%, 아래 35%, 오른쪽 21%(아래쪽 40% 구간)는 인스타 UI 영역이라 피한다. 컷에 따라 위치를 바꾸지 않는다.
- 박스: 컬러 박스, 불투명도 100% flat, 직사각형. 모서리 라운딩 없음.
- 글씨: Apple SD Gothic Neo SemiBold, 검정 `#111`, 크기 고정 72(시퀀스 1080 폭 기준, 폭의 약 6.8%), 자간 -3%에서 시작해 프리미어에서 눈으로 조정. 크기는 자막마다 바꾸지 않는다.
- 박스 가로 폭은 950px(좌우 안전 여백 6%) 이내. 넘으면 글자를 줄이지 말고 줄을 나눈다.
- 여백: 좌우 약 0.67em, 상하는 한글·대문자 잉크 기준 위아래 동일(프리미어에서 확인).
- 한 줄 12자 안팎, 자막 하나당 1~2초, 가운데 정렬.
- 한글·영문 폰트 혼용 금지, 하단 배치 금지, 불투명도 100% 미만 금지.

## 3. 산출물

1. `영상이름_색.srt` (색은 파일 이름에 표기). 예: `20261021_why backpack 3 reasons_블루.srt`
2. 선택한 색 이름·hex와 적용할 프리미어 캡션 스타일 이름(`자막_블루`, `자막_그린`, `자막_오렌지`, `자막_노랑`)
3. 프리미어 적용 체크리스트
   - 색은 SRT에 들어가지 않으므로, 프리미어에 컬러별 캡션 스타일을 한 번만 만들어 저장해 두고 적용한다.
   - 메뉴 이름과 패딩 분리 가능 여부는 프리미어 버전별로 확인이 필요하다. 안 되면 `.mogrt` 템플릿을 쓴다.
   - Apple SD Gothic Neo는 맥 전용이므로 자막 작업은 맥에서만 한다.

## 코드와의 관계

- 글자 수(12자), 자막 길이(1~2초), 글꼴 크기(72), 색 목록은 `reels/config.json`과 `reels/subtitles.py`에 있다.
- 한 줄만 쓴다는 기존 요청에 맞춰 줄 수는 1줄로 둔다. 규칙 문서의 "두 줄 이내"는 두 줄 자막을 허용한다는 뜻으로 읽고, 필요하면 `max_lines`를 2로 바꾼다.
